3. SBEMU.EXE - GNU GENERAL PUBLIC LICENSE, VERSION 2
----------------------------------------------------
SBEMU.EXE is a modified build of SBEMU (https://github.com/crazii/SBEMU),
Sound Blaster / OPL3 emulator for pure DOS, licensed under the GNU GPL
version 2. The full licence text is in GPL2.TXT.

SBEMU contains code from:
  * SBEMU - crazii and the SBEMU contributors;
  * MPXPlay sound card drivers - (C) 1998-2008 PDSoft (Attila Padar),
    http://mpxplay.sourceforge.net;
  * DOSBox DBOPL OPL emulator - (C) 2002-2021 The DOSBox Team (GPL);
  * TinySoundFont - Bernhard Schelling (MIT);
  * DJGPP C library and start-up code - DJ Delorie and others.

Changes made for SBUSB (Copyright (c) 2026 Lukasz Bolesta, with the help
of Claude; GNU GPL v2 or, at your option, any later version):
  * new USB Audio Class 1.0 / OHCI output and LINE IN driver
    (mpxplay/au_cards/sc_usbpcm.c, usbpcmct.h);
  * Sound Blaster 16 mixer volume table, SB Pro mixer mapping, optional
    L/R swap, memory allocation strategy at start-up (main.c, sbemu.c,
    au_cards.c, makefile).

Source code: the complete corresponding source of this SBEMU.EXE is in
SBEMUSRC.ZIP, distributed together with the program. Inside it,
SBEMU.DIF lists only the changes and BASECOMM.TXT names the original
SBEMU revision (github.com/crazii/SBEMU). If you pass SBEMU.EXE on, you
must pass on the source (or a written offer for it) and the GPL text.

DJGPP notice: SBEMU.EXE is built with DJGPP and contains DJGPP runtime
code. DJGPP is free and can be obtained from https://www.delorie.com/djgpp/
